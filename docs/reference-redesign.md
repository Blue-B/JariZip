# 화면 구성과 공고 정렬

## 첫 화면과 이용 안내

홈(`/`)은 `#/app/discover`로 바로 연결합니다. 검색창, 지역·직무·경력 조건과 공고 목록을 먼저 보여주며, 별도 시작 버튼을 누를 필요가 없습니다. 기존 `#/app`의 내 공간과 각 작업 화면 주소는 그대로 유지합니다.

이용 안내는 메뉴에서 `#/about`을 선택했을 때만 표시합니다. 네 가지 작업 화면의 사용법, 브라우저 저장·백업, 공고 출처와 기능 범위만 정리합니다. 이전의 큰 홍보 문구, 진한 배경 블록, 캐릭터 무대와 자동 움직임은 제거했습니다.

## 화면 원칙

밝은 청회색 배경, 흰 작업 영역, 읽기 쉬운 진회색 글자와 채도를 낮춘 파랑을 사용합니다. 선택한 메뉴는 옅은 파랑 배경과 진한 글자로 구분합니다. 첫 화면의 지피는 작은 브랜드 표식과 요청 시 여는 탐색 도움말에만 사용합니다. 도움말은 닫기 버튼이나 Escape로 닫으면 원래 버튼으로 초점을 돌려줍니다.

320px·360px·390px 모바일과 1440px PC에서 검색 조건, 정렬, 페이지 이동을 확인합니다. 자료 저장·백업·녹음·제출 스냅샷의 동작과 데이터 형식은 변경하지 않습니다.

## 정렬과 탐색

출처 기본순을 기본값으로 유지합니다. 마감일 가까운 순과 게시일 최신순은 현재 불러온 공고를 정렬하며, 더 불러오면 순서가 달라질 수 있음을 안내합니다. 마감일순에서는 예정된 마감, 날짜 미공개, 이미 마감된 공고 순으로 표시합니다. 게시일이 없으면 조회·검증 시각으로 대체하지 않습니다.

정렬을 바꾸면 첫 페이지로 돌아갑니다. 30/50개씩 보기, 자동 더 보기와 기존 버퍼는 유지하며 누적·출처별 건수는 표시하지 않습니다.

## 확인

기존 저장·백업·출처 오류·공고 이어보기 검사에 더해 홈 직접 진입, 브라우저 뒤로 가기, 이용 안내 링크, 좁은 화면에서의 검색·도움말, 키보드 초점과 움직임 최소화를 검사합니다. 브라우저 검사는 격리된 컨텍스트와 자동시험용 가상 공고를 사용하며 제품 화면에 시험 응답을 포함하지 않습니다. 검사 이미지는 `test-results/`에만 생성합니다.
