# 화면 구성과 공고 정렬

## 화면

소개 화면은 큰 제목, 코발트색 영역과 기존 지피 캐릭터를 중심으로 구성합니다. 포인터에 반응하는 캐릭터, 일시정지, 클릭 인사, 키보드로 선택할 수 있는 이용 흐름을 제공합니다. 기기의 움직임 최소화 설정에서는 자동 움직임과 포인터 기울기를 끕니다. 외부 사이트의 그림이나 캐릭터는 제품에 포함하지 않습니다.

작업 공간은 짙은 남색 내비게이션과 흰 작업 영역으로 분리합니다. 채용 목록은 회사·포지션·마감일을 구분하고, 반복되는 색상 카드와 장식을 줄입니다. 지피의 탐색 팁은 눌러서 열고 닫을 수 있습니다. 1440px PC, 390px·360px 모바일 화면을 브라우저 검사 대상으로 둡니다.

## 정렬과 탐색

출처 기본순이 기본값입니다. 마감일 가까운 순과 게시일 최신순은 서버 전체 결과가 아니라 현재 불러온 공고를 정렬합니다. 이 제한과 추가 조회 시 순서가 바뀔 수 있다는 안내를 선택 시 표시합니다.

마감일순에서는 아직 마감되지 않은 날짜를 먼저, 날짜가 없는 공고를 다음, 이미 마감된 공고를 마지막에 둡니다. 날짜만 제공된 마감은 한국 날짜의 마지막 시각을 기준으로 처리합니다. 게시일이 없으면 조회·검증 시각으로 대체하지 않습니다. 같은 날짜는 출처의 기존 순서를 유지하고 원본 배열을 변경하지 않습니다.

정렬 변경 시 첫 페이지로 돌아갑니다. 30/50개씩 보기, 자동 더 보기와 기존 버퍼는 유지합니다. 누적 건수나 출처별 건수는 추가하지 않습니다. 문서, 저장한 공고, 지원 이력과 제출 스냅샷에는 마이그레이션이나 삭제를 수행하지 않습니다.

## 검증

```bash
npm run typecheck
npm test
npm run build
CI=1 JARIZIP_TEST_PORT=4197 npm run test:e2e
```

`src/lib/jobSort.test.ts`는 미공개·잘못된 날짜, 마감 상태, 동률, 한국 날짜와 원본 불변성을 검사합니다. `tests/e2e/reference-redesign.spec.ts`는 정렬 변경, 30/50개 보기·자동 이어보기 유지, 키보드 팁, 모바일 범위, 이용 흐름 전환과 포인터 일시정지를 검사합니다. 기존의 데이터 보존·녹음·백업·출처 오류·모바일 탐색 검사도 그대로 유지합니다.

브라우저 검사는 격리된 컨텍스트와 명시적인 자동시험용 가상 공고를 사용합니다. 검사 이미지는 `test-results/` 또는 Git에서 제외한 `.local/`에 생성하며 저장소에 올리지 않습니다. 실제 서비스 화면은 기존 외부 공고 연결을 유지하며 시험용 응답을 포함하지 않습니다.

이번 변경에서 TypeScript 검사, 배포 빌드, 단위 검사 139개, 서버 검사 31개를 확인했습니다. 최종 격리 빌드에서 브라우저 검사 49개가 모두 통과했습니다. 마감일·게시일 정렬, 정렬 변경 시 첫 페이지 복귀, 30/50개 보기와 자동 이어보기, 키보드로 여는 지피 팁, 움직임 일시정지 및 모바일 말풍선 위치를 확인했습니다. PC와 모바일의 첫 화면·작업 공간 캡처를 직접 확인했습니다.
