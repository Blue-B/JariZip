# JariZip 베타 사용자 5명 모집 · 10분 사용 테스트

JariZip은 여러 회사에 지원할 때 **공고, 제출한 서류 버전, 지원 단계를 한곳에 기록**하는 무료 로컬 앱입니다. 실제 취업 준비 중인 분의 첫 사용 경험을 확인하고 싶습니다.

## 누구를 찾나요?

- Windows PC에서 실제 취업 준비를 하고 있고 10분 정도 사용해 볼 수 있는 분
- 개발 직무가 아니어도 됩니다. 개발 지식이나 API 키는 필요 없습니다.
- 참여에 금전적 보상은 없습니다. 체험 후 계속 사용할 의무도 없습니다.

## 사용해 볼 작업 (총 10분)

1. [JariZip v0.1.0 Beta Release](https://github.com/Blue-B/JariZip/releases/tag/v0.1.0)에서 Windows 포터블 EXE를 확인합니다. 파일은 코드 서명되지 않아 SmartScreen 경고가 나올 수 있습니다. 출처를 확신할 수 없다면 실행하지 말고 그 이유를 알려주세요.
2. 앱을 열고 **API 키를 발급받지 않은 상태**에서 공고 하나를 직접 등록합니다. 테스트에는 가상의 회사명과 가상 공고를 사용해도 됩니다.
3. 등록한 공고의 **지원 준비** 공간을 만들어 봅니다.
4. 테스트용 가상 이력서 내용을 서류로 저장하고 제출본 버전 표시를 찾아봅니다.
5. 앱을 닫았다 다시 열어 기록이 유지되는지 확인합니다.

**실제 이력서, 개인정보, API 키, 지원 내역은 절대 공유하지 마세요.** 버그 화면을 첨부하는 경우 회사명·계정·서류 내용·개인정보를 가리고 올려주세요.

## 가장 알고 싶은 내용

- 첫 화면에서 무엇을 해야 하는지 바로 알 수 있었나요?
- API 키 없이 공고 하나를 등록할 수 있었나요? 어느 단계에서 막혔나요?
- 실제 지원에 쓰고 싶나요? 아니라면 그 이유는 무엇인가요?
- 사용하는 OS와 오류 메시지(개인정보 제외)는 무엇인가요?

[**피드백 작성하기 (GitHub 계정 필요)**](https://github.com/Blue-B/JariZip/issues/new?template=beta-feedback.yml) · [프로젝트 실제 화면 보기](preview/)

GitHub 계정이 없다면 우선 Issue를 만들 필요 없이 공개 소개 글에 의견을 남겨도 됩니다. 별도 설문 서비스나 개인정보 수집 창구는 운영하지 않습니다.

## 테스트 중단 기준

실행 경고가 불안하거나 10분 안에 첫 공고 등록에 실패한다면 더 시도하지 않아도 됩니다. 어느 단계에서 막혔는지가 중요한 피드백입니다. 정상 실행·저장·복구는 모든 Windows 환경에서 아직 확인된 것이 아닙니다.
