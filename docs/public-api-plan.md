# 자리집 공용 채용 API 운영 검토

확인 기준: 2026-09-26. 이 문서는 연동 신청과 운영을 위한 검토안이며, 제공사 승인이나 공개 서버 배포가 완료됐다는 뜻이 아닙니다. 이용 조건은 신청 시 다시 확인해야 합니다.

## 공용 서비스와 공개 키는 다릅니다

검토할 구조는 `이용자 브라우저 → 자리집 서버 → 승인받은 채용 API`입니다. 제공사가 자리집의 공개 서비스 목적을 승인하면 이용자가 각자 발급받지 않고 서버가 데이터를 조회해 승인된 범위 안에서 보여주는 방식을 적용할 수 있습니다. 발급받은 비밀키를 GitHub, 프런트엔드, 설치 파일, 이용자 백업에 포함하는 방식은 적용하지 않습니다. 오픈소스 코드의 MIT 라이선스가 외부 채용 데이터나 키의 재배포 권한까지 부여하지는 않습니다.

현재 프로젝트는 로컬 실행용입니다. 공식 승인된 공용 중계 서버, 일일 공용 한도 관리, 공개 운영 보안, 제공사와의 별도 계약은 아직 구성하지 않았습니다. 현재 로컬 베타는 원티드·점핏·직행의 비공식 자동 조회를 중단했습니다. 기존 연결의 기술적 조회 성공을 이용 허가로 해석하지 않습니다. 조회 가능한 응답이라는 사실만으로 대규모 재배포나 상업적 이용이 허용됐다고 해석하지 않습니다.

## 제공사별 확인

### 사람인

- 이용신청 승인과 앱별 access-key 발급 절차가 있습니다. API 소개는 맞춤형 채용 검색 서비스·애플리케이션 활용을 안내합니다.
- 사용안내에는 1일 최대 500회 호출로 명시되어 있습니다. 사용자 모두의 요청이 같은 키 한도를 사용하므로 공개 서비스에는 허용된 범위의 캐시와 요청 병합, 일일 예산 제어가 필요합니다. 주의사항 페이지의 표현과 다른 세부 산정은 승인 시 확인합니다.
- 주의사항은 키 공개·공유, API를 사용한 서비스의 재판매·이용요금 부과 및 이용 대가 수취를 제한합니다. 무료 공개 서비스도 자동 승인된다는 의미는 아닙니다. 광고·유료 부가기능과의 결합은 제공사에 사전 확인합니다.
- 출처 표시 및 원문 연결 의무를 준수해야 합니다. 로컬의 사람인 어댑터는 키 미설정 상태이며 실제 키로 검증하지 않았습니다.

공식 안내: https://oapi.saramin.co.kr/guide/info
소개 및 출처 표시: https://oapi.saramin.co.kr/introduce
주의사항: https://oapi.saramin.co.kr/caution
신청: https://oapi.saramin.co.kr/join

### 고용24

정부 채용 연동은 고용24의 채용정보 Open API를 우선 검토합니다. 공식 소개는 기업회원 전용이며 로그인 후 서비스별 신청, 담당자 검토·승인, 인증키 발급 절차를 안내합니다. 키를 타인에게 양도하지 않는 조건도 있습니다. 개인 개발자가 바로 받을 수 있다고 보장하지 않습니다. 신청 주체 자격, 공개 서비스 목적, 채용정보 재표시·보관 범위는 별도로 확인합니다.

목록 어댑터는 `callOpenApiSvcInfo210L01.do`(callTp=L, returnType=XML, startPage 1-based, display 최대 100), 상세 어댑터는 `callOpenApiSvcInfo210D01.do`(callTp=D, infoSvc=VALIDATION, wantedAuthNo)를 사용합니다. 서버는 발급받은 `WORK24_AUTH_KEY`가 있을 때만 고용24를 활성화합니다. 결과에는 원문 링크와 출처 표시를 함께 노출하고, 목록의 총건수는 저장 공고 수로 오인하지 않습니다. 응답은 외부 엔터티·DTD를 허용하지 않는 제한된 XML 파서로만 읽고, 본문은 다시 일반 텍스트로 변환해 렌더링합니다.

공식 안내: https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do

### 잡코리아

공식 API가 있으며 공공기관·학교 우선 제공입니다. 공식 안내와 FAQ는 개인·일반기업·개인사업자에 대해 내부 검토로 제공 여부가 결정된다고 설명합니다. 운영 중인 사이트, 이용 목적, 신청 기관 및 서버 정보가 필요하고, 신청한 IP 등록 후 고유 호출 링크가 발급됩니다. 자리집과 같은 개인 오픈소스 서비스의 승인을 전제로 개발하거나 연결됐다고 표시하지 않습니다. 신청 약관과 담당자의 서면 확인을 먼저 받습니다. 상세요강과 지원은 잡코리아 원문으로 연결하는 조건을 확인합니다.

공식 안내 및 문의: https://www.jobkorea.co.kr/service/api

### 그룹바이 및 기타 채용 사이트

그룹바이 공식 사이트에서 누구나 이용신청해 발급받는 공개 채용 API 문서는 이번 조사로 확인하지 못했습니다. 이는 API가 절대 없다는 뜻이 아닙니다. 공개 배포 목적과 필요 필드를 설명해 데이터 제휴 가능 여부를 문의할 대상으로 둡니다. 다른 사이트도 공식 피드·API·제휴를 먼저 확인하고, 접근 제한을 우회하거나 비공개 인증 정보를 사용하지 않습니다.

공식 사이트: https://groupby.kr/

공공데이터포털도 데이터셋마다 제공 범위와 라이선스가 다릅니다. 특정 기관의 채용 데이터가 전국 민간기업 전체 공고를 포함한다고 해석하지 않으며, 비상업·변경금지·출처표시 등 개별 조건을 확인해야 합니다.

## 신청 전에 결정할 사항

공개 서비스 주소, 실제 신청 주체와 연락처, 무료·유료 운영 계획, 예상 이용량, 필요한 공고·기업 필드, 원문 링크 및 출처 표시 형태를 정합니다. 제공사에 공개 서비스 이용, 서버 캐시 허용 기간, 개인 보관 및 백업 범위, 상업 이용, 한도 증설, 종료·정정 요청 반영 조건을 함께 질문합니다. 아직 정해지지 않은 기관명·도메인·예상 이용자 수를 임의로 작성하지 않습니다.

신청 설명 초안:

> 자리집은 이용자가 채용 공고를 찾아 개인 보관함에 정리하고 서류 버전과 지원 준비를 관리하는 서비스입니다. 채용 검색과 원문 링크를 제공하며 이력서·녹음은 외부 채용 API에 전송하지 않습니다. 운영자 서버에서 인증키를 보관하고, 이용자에게 키나 원시 데이터 API를 재배포하지 않는 구성을 검토합니다. 공개 서비스 제공, 출처 표시, 허용되는 캐시·개인 저장 범위와 이용량 조건을 확인하고자 합니다.

## 승인 이후 구현할 운영 기능

승인된 출처만 서버에서 활성화하고, 각 제공사의 한도와 허용 보관 기간을 코드에 반영합니다. 동일 검색은 허용된 기간 안에서 재사용하고 출처별 동시 요청·일일 한도를 제한합니다. 비밀키와 고유 호출 URL은 로그에서도 가립니다. 만료·차단·한도 초과는 사용자에게 그대로 안내하고 다른 출처 결과를 유지합니다. 캐시가 불허되면 저장하지 않습니다. 로컬 이용자의 서류·녹음·지원 기록을 중앙 서버로 옮기는 일은 별도 동의 설계 없이 하지 않습니다.
