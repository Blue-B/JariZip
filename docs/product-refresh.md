# 자리집 제품 화면 개편

시안 이미지만 추가한 것이 아니라 랜딩과 작업 화면의 React·CSS, 실제 저장·편집 흐름을 함께 변경했습니다. 기존 브라우저 자료의 저장 형식은 유지하며 자동으로 초기화하지 않습니다.

## 화면과 캐릭터

지피의 투명 AVIF 두 포즈를 랜딩, 대시보드, 사이드바에서 실제 이미지 요소로 사용합니다. 화면 전체를 이미지로 대체하지 않았습니다. 제목, 검색, 탭, 입력창, 버튼은 HTML로 동작합니다.

밝은 종이색과 짙은 남색 본문, 코발트색 버튼을 공고·지원·서류·면접·기업 노트·템플릿·설정에 일관되게 적용했습니다. 휴대폰에는 주요 화면으로 이동하는 하단 탐색을 추가했습니다. 랜딩의 글자와 문단 간격, 대시보드 제목 줄바꿈, 태블릿의 서류 업로드 영역도 보완했습니다.

시각적 위계와 탐색 흐름을 별도로 검토했습니다. 검토에서 발견한 모바일 검색 버튼의 접근 가능한 이름, 캐릭터 인사 말풍선의 위치, 저장 알림과 하단 탐색의 겹침을 수정하고 회귀 테스트를 추가했습니다.

모든 체험 자료는 가상 예시입니다. 사용자 수, 합격률, 후기, 가격표, 앱스토어 배지를 꾸며 넣지 않았습니다.

## 실제 동작

### 대시보드와 일정

관심 공고, 진행 중 지원, 면접 준비, 서류 수는 보관 자료에서 계산합니다. 준비 안내는 실제 자료를 확인하고 다음 작업으로 연결합니다. 제출본이 있는 다가오는 면접은 해당 지원 건의 연습 화면으로 바로 이동합니다.

주간 일정은 저장된 면접 일시를 사용합니다. 이전·다음 주, 이번 주 이동과 날짜 선택이 가능하고, 일정 카드는 실제 지원 기록 편집으로 이어집니다. 공고 추가·서류 작성 바로 가기는 각각 입력창을 엽니다.

### 공고 보관과 수정

여러 검색어가 서로 다른 필드에 걸쳐 있어도 모두 포함된 공고를 찾습니다. 고용 형태, 지역, 접수 상태, 관심 여부와 제외 키워드를 함께 적용할 수 있습니다. 중복 판단에서는 일반적인 광고 추적값만 제외하고 원본 주소, 공고 ID, 해시 라우팅은 보존합니다.

직접 보관한 공고는 다시 편집할 수 있습니다. 현재 목록의 공고를 고쳐도 지원 당시 스냅샷과 제출본은 바뀌지 않습니다. 편집 후 접수 상태는 미확인으로 돌아가며, 원문을 확인한 뒤 다시 수동으로 기록합니다. 공백뿐인 회사명·포지션, 게시일보다 빠른 마감일을 거부하고 중복 기술 태그는 제거합니다.

### 서류와 입력 보호

기존 업로드·텍스트 추출·버전별 다운로드·제출본 고정·면접 답변·녹음·백업 복원을 유지했습니다. 서류 또는 공고를 작성하다 Escape, 취소, 닫기를 누르면 저장하지 않은 내용을 버릴지 확인합니다. 계속 작성을 선택하면 입력한 내용이 그대로 남습니다. 저장하지 않은 내용이 있을 때 탭을 닫으려 하면 브라우저의 이탈 확인을 요청합니다.

이 확인은 자동 초안 저장이 아닙니다. 기기 종료나 브라우저 강제 종료까지 복구를 보장하지 않습니다.

### 저장 완료와 실패

완료 안내는 IndexedDB 트랜잭션이 실제로 끝난 뒤 표시합니다. 용량 부족이나 쓰기 실패에는 저장 성공 문구를 표시하지 않습니다. 저장소를 사용할 수 없으면 현재 화면에만 반영됐음을 알리고 백업을 안내합니다. 모바일 알림은 하단 탐색 위쪽에 놓아 화면 이동을 막지 않습니다.

## 최종 검증 범위

아래 명령으로 코드 검사, 배포 빌드, 단위 테스트 125개와 브라우저 테스트 28개를 확인합니다.

```bash
npm run typecheck
npm test
npm run build
CI=1 JARIZIP_TEST_PORT=4182 npm run test:e2e
```

브라우저 검사는 개인 프로필이나 실제 마이크가 아닌 격리된 컨텍스트와 합성 오디오를 사용합니다.

- 랜딩과 작업 화면 8개의 1440px·390px 캡처, 실제 캐릭터 파일 디코딩과 동일 출처 제공.
- 360px·768px·1024px에서 랜딩·대시보드·공고·서류의 가로 넘침 확인.
- 검색·필터·중복 링크, 공고 수정 후 새로고침, 수정 전 지원 원문 보존.
- 문서 v1 제출 후 v2를 편집해도 제출 근거는 v1로 유지.
- 서류·공고 초안의 닫기 확인, 계속 작성, 명시적인 버리기, 중첩 창의 스크롤 복원.
- 저장 용량 오류를 강제로 발생시킨 뒤 허위 성공 안내가 없는지와 기존 데이터 유지 확인.
- 문서 원본 다운로드, 답변·녹음 저장·재생·새로고침, 백업 왕복과 잘못된 백업 거부.
- 모바일 검색의 접근 가능한 이름, 메뉴·본문 건너뛰기, 하단 탐색, 캐릭터 말풍선의 위치.

검사 도중 태블릿 서류 업로드 영역의 너비 초과와 모바일 말풍선의 화면 밖 배치를 발견해 수정했습니다. 실패한 상태를 최종 통과로 간주하지 않으며 수정 후 다시 검사합니다. 캡처와 브라우저 검사 결과는 `test-results/`에 생성되고 Git에 포함하지 않습니다.

## 제공하지 않는 기능

실시간 채용공고 수집, 외부 사이트 자동 접수 확인, LLM 자소서 생성·면접 평가, 음성 전사, 계정·서버 동기화, 기업으로의 자동 지원 전송은 연결하지 않았습니다. 공고는 직접 보관하고 접수 상태는 수동으로 기록합니다. 면접 질문은 준비된 로컬 규칙에 따라 구성됩니다.

브라우저 저장소는 암호화 보관함이 아닙니다. 다른 기기로 옮길 때는 백업이 필요합니다. 이번 검증은 모든 브라우저·실제 스마트폰 하드웨어에 대한 인증이나 운영 보안 감사가 아닙니다. 공개 도메인 배포와 운영 인프라는 별도로 구성해야 합니다.
