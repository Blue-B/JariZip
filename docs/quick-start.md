# JariZip 처음 사용하기

Windows 데스크톱 앱 기준 안내입니다.

## 1. 앱 실행

GitHub Release에 게시되는 Windows 설치 파일 또는 포터블 EXE를 실행합니다. 앱 자체에 Node.js와 로컬 조회 서버가 포함되므로 별도로 Node.js를 설치할 필요가 없습니다.

> 현재 저장소에는 패키징 기능까지 준비되어 있으며, 공개 Release 파일은 아직 게시하지 않았습니다.

## 2. 채용공고 연결

처음 실행하면 연결 마법사가 자동으로 열립니다.

1. **고용24 연결하기**를 선택합니다. 고용24를 우선 권장합니다.
2. **고용24 Open API 안내 열기**를 눌러 공식 신청 페이지를 엽니다.
3. 본인 인증키를 발급받아 JariZip 입력창에 붙여넣습니다.
4. **저장하고 연결 확인**을 누릅니다.
5. 실제 공고 응답을 확인하면 연결 완료입니다.

사람인도 같은 방식으로 연결할 수 있습니다.

API 키는 데스크톱 앱의 운영체제 보안 저장소에 암호화해 보관하며, 브라우저 저장소나 JariZip 백업 파일에는 넣지 않습니다.

연결을 나중에 하려면 **나중에 하기**를 눌러도 됩니다. API 없이도 공고를 직접 추가해 지원 기록·서류 관리 기능을 사용할 수 있습니다.

## 3. 공고 찾기

![공고 화면](preview/jobs.png)

채용 탐색에서 키워드·지역·직무·경력 조건으로 찾습니다. 공식 API 결과라도 지원 전에는 원문에서 모집 상태와 마감 시간을 다시 확인하세요.

## 4. 서류와 지원 기록 관리

![서류 보관함](preview/documents.png)

서류를 수정하면 이전 파일을 덮어쓰지 않고 새 버전으로 보관합니다.

![지원 현황](preview/applications.png)

지원 기록에는 그 시점의 공고와 실제 제출한 서류 버전을 연결해 남깁니다.

## 5. 백업

설정에서 **전체 백업 내려받기**를 사용합니다.

- 자료는 현재 PC에 저장됩니다.
- 자동 클라우드 동기화는 없습니다.
- 전체 JSON 백업은 40MB까지 지원합니다.
- 백업은 암호화되지 않으므로 다른 사람에게 공유하지 마세요.

## 연결을 바꾸고 싶을 때

**설정 → 공고 연결 → 연결 설정**에서 고용24·사람인 키를 추가하거나 삭제할 수 있습니다.
