# 채용 탐색 페이지와 화면 개편

> 과거 화면 개편의 검증 기록입니다. 현재 배포에서는 원티드·점핏·직행 비공식 자동 조회를 제공하지 않습니다. 공고 직접 기록과 선택적인 공식 출처 사용에 관한 최신 내용은 [README](../README.md)를 확인하세요.

## 반영한 동작

- 기본 30개씩 보기, 선택 시 50개씩 보기. 일반 모드는 이전·다음 페이지로 이동합니다.
- 스크롤할 때 자동으로 더 보기를 켜면 페이지 전환 없이 선택한 단위로 기존 목록 아래에 공고가 추가됩니다. 마지막 구간은 남은 공고만 보여줍니다.
- 출처별 고정 페이지 크기는 화면의 표시 단위와 분리했습니다. 불러온 여분의 공고는 메모리에서 보관해 다음 페이지에 이어서 사용하며, 같은 원문 주소는 중복 표시하지 않습니다.
- 누적 공고 수와 플랫폼별 건수 표시는 제거했습니다. 부분 조회 실패는 접을 수 있는 안내로 남깁니다. 공고별 출처명은 유지합니다.
- 회사·포지션/근무조건·마감을 구분한 목록을 적용했습니다. D-day와 마감 날짜를 분리하고 임박한 마감은 별도로 강조합니다. 날짜가 없는 경우 상시채용·채용 시 마감·미공개를 출처 정보에 맞춰 구분합니다.
- 기업 업종 및 출처가 제공하는 직원 수 구간·설립기간, 상세의 홈페이지 정보를 표시합니다. 제공되지 않은 기업 규모나 연봉을 추정하지 않습니다. 해당 출처가 검증된 기업정보 전체를 제공한다고 보장하지 않습니다.

## 화면

캐릭터 원본은 유지합니다. 작업 공간·모달·첫 화면에 종이색, 짙은 녹색, 잉크색의 공통 색상과 정돈된 구분선을 적용했습니다. 탐색 화면은 비교하기 쉬운 행 중심으로 바꾸고, 작은 부가정보보다 회사·포지션·마감의 위계를 높였습니다. Pretendard Variable을 로컬 패키지에서 제공하며 외부 글꼴 서버에 접속하지 않습니다. 작은 글꼴 조각도 같은 출처의 파일로 출력해 CSP와 충돌하지 않도록 했습니다.

## 확인 결과

- TypeScript 검사, 배포 빌드 완료.
- 단위 검사 135개, 서버 검사 31개, 격리된 브라우저 검사 46개 통과.
- 30/50개 페이지 전환, 다음 페이지를 위한 여분 공고 보존, 자동 모드 30→60 및 50→100, 실패 시 이전 목록 유지·같은 구간 재시도, 빈 응답에서 자동 조회 일시정지, 검색 변경 후 이전 응답 차단을 검사했습니다.
- 마감 날짜와 D-day 분리, 출처 기반 회사 정보 및 미제공 처리, 360px·390px 모바일과 데스크톱 화면을 검사했습니다.
- 실제 외부 서비스 조회에서 세 출처의 검색·상세·저장·지원 준비·새로고침 후 원문 유지, 연속 조회를 확인했습니다. 이는 검사 시점의 결과이며 이후 외부 서비스의 가용성을 보장하지 않습니다.
- 시각 개편 과정에서 발견한 좁은 화면의 선택 상자·상단바·캐릭터 영역 넘침을 수정한 뒤 브라우저 검사를 다시 실행했습니다.
