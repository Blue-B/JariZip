# 로컬 실행형 공개 범위

## 배포 형태

현재 결과물은 Node.js로 실행하는 한국어 로컬 웹 앱입니다. 코드 공개와 공용 웹 서비스 운영은 별개입니다. 내려받아 실행하는 사용자가 자기 PC에서 조회 서버를 실행하고 같은 PC의 브라우저로 접속합니다. 별도의 운영자 공용 서버, 사용자 계정, 중앙 이력서 DB는 필요하지 않습니다.

Windows에서는 `start-jarizip.cmd`, macOS/Linux에서는 `sh start-jarizip.sh`를 사용합니다. 시작 파일도 Node.js 22.12 이상이 설치되어 있어야 하며, 최초 패키지 설치는 인터넷을 사용합니다. `node scripts/local.mjs --prepare`로 설치·빌드만, `npm run local:check`로 실행 환경만 검사할 수 있습니다.

직접 실행하는 방법:

```bash
npm ci
npm run build
npm start
```

한 주소(`http://localhost:4178/`)를 계속 사용하세요. 서버는 기본적으로 `127.0.0.1`에만 바인딩합니다. 포트나 호스트를 바꾸면 브라우저 저장 영역이 달라질 수 있습니다. 사용을 끝낼 때 터미널에서 Ctrl+C로 종료합니다. Linux/WSL용 `preview:start` 보조 스크립트는 Windows 일반 터미널용 설치기가 아닙니다.

현재 Windows/macOS 설치 프로그램, Node.js가 포함된 실행 파일, 자동 업데이트, 공용 웹 배포는 제공하지 않습니다. 소스 ZIP만 내려받아 두 번 클릭하는 배포물로 설명하지 마세요. 스마트폰 브라우저 레이아웃 검증은 스마트폰 단독 설치 지원을 의미하지 않습니다.

## 실제 기술 구성

- 화면: React, TypeScript, React Router, CSS, Pretendard. Vite로 빌드합니다.
- 조회 서버: Node.js 기본 `node:http`와 `fetch`. Python/FastAPI나 Express 서버가 아닙니다.
- 개인 자료: 브라우저 IndexedDB, `idb-keyval`. 서버에 이력서나 녹음을 저장하지 않습니다.
- 문서: `pdfjs-dist`의 PDF 텍스트 추출, `mammoth`의 DOCX 텍스트 추출.
- 입력 검사: Zod. 자동 검사: Vitest, Node 테스트, Playwright.
- 조회 캐시: 서버 프로세스의 메모리 Map, 60초 캐시와 중복 조회 합치기. Redis, Kafka, PostgreSQL, SQLite, 외부 검색 서버는 사용하지 않습니다.

지금의 로컬 사용에서 Redis나 Kafka를 필수 설치 대상으로 추가하지 않습니다. 공용 서버 여러 대의 캐시·요청 한도를 공유하거나 대규모 이벤트를 여러 처리기로 전달하는 요구가 생기면 그때 별도로 설계합니다.

## 데이터와 제한

새 작업 공간에 가상 공고·서류·지원 내역을 채우지 않습니다. 이전 설치에 남은 예시를 사용자의 확인 없이 삭제하지 않습니다. 이력서, 녹음과 백업을 저장소나 공개 이슈에 올리지 마세요.

전체 JSON 백업은 UTF-8 파일 크기 기준 40MB까지 내보내고 불러옵니다. 원본의 base64 표현과 JSON 구조 때문에 원본 파일들의 합보다 커질 수 있습니다. 한도를 넘으면 복원이 불가능한 일반 백업을 만들지 않고 안내합니다. 원본을 삭제하거나 줄이지 않습니다. 40MB 초과 작업 공간의 분할 백업·대용량 복구는 아직 지원하지 않습니다. 중요한 문서의 원본 파일은 별도로 안전하게 보관하세요.

브라우저 데이터 삭제, 다른 브라우저/프로필/주소 사용은 데이터 위치 변경 또는 손실로 이어질 수 있습니다. 백업은 암호화 파일이 아닙니다. 공용 기기에서는 개인정보를 입력하지 마세요. 기존 버전의 탭은 닫고 새 버전으로 다시 여세요.

## 외부 채용 출처

로컬 실행이나 코드 공개가 외부 사이트의 수집·재배포·상업적 이용 허가를 대신하지 않습니다. 연결 코드의 MIT 라이선스도 외부 채용 데이터에 대한 권리를 부여하지 않습니다. 각 제공자의 허용 범위와 승인이 확인되지 않았다면 '자유롭게 수집·재판매 가능'으로 안내하지 마세요.

원티드 약관 안내: https://www.wanted.co.kr/terms
사람인 공식 API 안내: https://oapi.saramin.co.kr/guide/info
고용24 Open API 안내: https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do

원티드·점핏·직행 비공식 API 자동 조회는 네트워크 호출 전에 차단합니다. 원문 링크 이동과 사용자 직접 기록은 유지하며, 기존 자료는 자동 삭제하지 않습니다. 사람인·고용24 공식 API도 발급·승인 범위에서 본인의 키로 사용해야 합니다. 고용24 결과는 원문 링크와 출처 표시를 함께 제공합니다. 실패를 가상 결과로 대체하지 않습니다. 공고를 앱에서 준비·보관하는 기능은 기업으로 지원서를 보내는 기능이 아닙니다.

## 공개 전 남은 검증

공개 소스 기반의 개발자 베타와 일반 사용자용 설치판을 구분합니다. 설치판을 내기 전에는 새 PC에서의 설치/종료/업데이트, 실제 Windows/macOS와 모바일 브라우저 호환성, 대용량 자료, 라이선스와 비밀정보 검사, 개인정보·출처 안내를 확인해야 합니다. 현재 연결의 제공사 허용 범위도 별도로 확정해야 합니다. 이 문서가 공개 호스팅이나 유료 서비스의 운영 승인을 의미하지는 않습니다.
