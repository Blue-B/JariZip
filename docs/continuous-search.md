# 연속 공고 탐색과 마감일 검증

> 과거 자동 조회 구현의 기록입니다. 현재 비공식 원티드·점핏·직행 연결은 중단되어 있으며, 페이지 이동·마감 정렬은 허용된 출처의 응답과 시험용 데이터로 검사합니다. 현재 제공 범위는 [README](../README.md)를 확인하세요.

검증일: 2026-09-26. 실제 공개 출처 검사는 이 실행 시점의 결과이며 향후 응답이나 모든 공고의 접수 가능성을 보장하지 않습니다.

## 확인한 원인

기존 원티드·점핏·직행 배지의 숫자는 전체 공고 수가 아닌 현재 페이지에서 상태·조건을 적용한 건수였습니다. 통합 검색은 모든 출처에 같은 페이지 번호를 보내므로 원티드와 점핏의 결과가 끝나도 직행 결과가 있는 동안 다음 페이지가 활성화됐습니다. 원티드의 `/api/v4/jobs`가 마지막 결과 이후 `data: null`, `links.next: null`을 반환하는 경우를 실제 요청으로 재현했습니다. 이전 코드는 이 정상 종료 응답을 목록 형식 오류로 표시했습니다.

## 변경한 동작

출처별 조회 위치를 담은 이어보기 정보는 검색 조건과 결합되어 있습니다. 결과가 끝난 출처는 더 요청하지 않고, 실패한 출처는 실패한 위치에서 다시 시도합니다. 희소한 필터 결과는 한 요청에서 출처당 최대 세 페이지까지 보충합니다. 10초가 지난 뒤 추가 페이지 요청을 시작하지 않으며 각 외부 요청에는 별도 제한 시간이 적용됩니다.

브라우저는 기존 공고를 남기고 새 공고를 아래에 추가합니다. 같은 원문 주소는 중복 표시하지 않으며 배지는 누적 공고 수와 이번 조회 상태를 구분합니다. 자동 이어보기는 사용자가 켤 수 있습니다. 추가 결과가 없거나 출처 오류가 있으면 자동 조회를 멈추고 수동 더 보기를 남겨 무한 요청을 방지합니다. 검색 조건을 바꾸면 진행 중 요청을 취소하고 이전 검색의 응답이 섞이지 않게 합니다.

기존 50페이지 제한은 제거했습니다. 출처가 제공한 마지막 결과, 반복 구간 감지, 조회 제한은 그대로 따릅니다. 숫자 입력의 안전 상한은 출처당 10,000페이지이며, 출처 자체의 결과 수·페이지 제한이 먼저 적용될 수 있습니다. 실제 무한한 공고를 생성하거나 접속 제한을 우회하는 기능은 아닙니다.

## 마감일

목록에서 날짜와 D-day를 보여주고, 출처가 명시한 상시채용·채용 시 마감은 별도로 표시합니다. 날짜와 명시적 유형이 없으면 마감일 미공개로 남깁니다. D-day는 한국의 달력 날짜를 기준으로 계산하고 날짜만 있는 원티드 응답은 해당 한국 날짜의 끝을 기준으로 처리합니다. 상세에는 날짜를 보여주되 정확한 종료 시각은 원문 확인을 안내합니다.

`deadlineType`은 선택 필드이므로 기존 저장 자료와 지원 당시 스냅샷은 필드가 없어도 읽을 수 있습니다. 신규 필드는 저장·검증·백업 과정에서 보존합니다. 이 변경은 사용자 서류나 지원 기록을 외부로 보내지 않습니다.

## 실행 결과

- TypeScript 검사와 배포 빌드 완료.
- 단위 검사 135개, 서버 검사 28개, 격리된 브라우저 검사 44개 통과.
- 외부 사이트 직접 조회에서 통합 검색 네 구간을 이어 읽어 누적 56 → 112 → 168 → 224개의 서로 다른 원문 주소를 확인했습니다. 네 구간 합계는 원티드 80건, 점핏 64건, 직행 80건이었습니다. 필터 없는 검색의 이 실행 결과이며 사이트 전체 공고 수가 아닙니다.
- 원티드의 실제 마지막 구간 응답은 조회 실패가 아닌 공고 0건·다음 결과 없음으로 처리되는 것을 확인했습니다.
- 실제 출처별 상세 열기, 브라우저 저장, 지원 준비, 새로고침 후 스냅샷 유지 검사를 다시 실행했습니다.
- 자동시험으로 출처별 조기 종료, 부분 장애 후 같은 구간 재시도, 반복 응답 차단, 희소 결과 보충, 50페이지 이후 진행, 잘못된 이어보기 정보 거부, 중복 주소 제거, 추가 조회 실패 시 기존 목록 유지, 오래된 응답 격리, 자동 조회 일시 정지, 한국 날짜 경계와 이전 자료 호환을 확인했습니다.
- 데스크톱과 390px·360px 모바일 캡처에서 누적 건수·마감일·이어보기 조작과 가로 넘침 여부를 확인했습니다. 시험용 화면은 가상 자료만 사용하며 실제 공개 공고 검사와 구분합니다.

## 남는 한계

원티드의 분야 조건 등 일부 필터는 출처가 반환한 페이지 안에서 추가 적용됩니다. 지역·분야·경력의 분류가 출처마다 같지 않으므로 검색의 완전성을 보장하지 않습니다. 서로 다른 사이트에 재등록된 동일 채용은 원문 주소가 달라 별개 공고로 보일 수 있습니다. 제공되지 않은 마감일·게시일·급여는 만들어 넣지 않습니다. 사람인은 실제 발급 키가 없어 실서비스 검사 대상에 포함하지 않았습니다.
