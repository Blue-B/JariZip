# JariZip · 자리집

<img src="public/brand/jippi-wave.avif" width="180" alt="지퍼 파우치 캐릭터 지피" />

**실제 공고를 찾고, 제출한 서류를 기억하고, 내 이야기로 면접을 준비하는 한국어 취업 워크스페이스.**

## 시작하기

Node.js 22.12 이상이 필요합니다.

```bash
npm ci
npm run build
npm start
```

`http://localhost:4178/#/app/discover`에서 실제 공고를 검색합니다. 개발 중에는 `npm run dev`를 사용합니다. 개발 서버에도 동일한 조회 API가 연결됩니다. 기존 Vite 정적 미리보기가 떠 있다면 중지하고 위 명령으로 다시 실행하세요.

Linux/WSL의 프로젝트 전용 실행 보조 명령은 `npm run preview:start`, 중지는 `npm run preview:stop`입니다. 다른 프로세스는 종료하지 않습니다. 사용 중인 포트를 바꾸려면 `npm start -- --port 4180`을 사용하세요.

## 실제 공고 연결

- **원티드:** 공개 목록·검색·상세 응답을 서버에서 읽습니다. 별도 키 없이 사용할 수 있지만 공식 제휴 API는 아니며 출처 변경이나 접근 제한으로 중단될 수 있습니다. 제한을 우회하거나 실패를 예시 공고로 대체하지 않습니다.
- **사람인:** 서버의 `.env.local`에 `SARAMIN_ACCESS_KEY`를 설정한 경우 선택할 수 있는 공식 API 연결입니다. 승인·사용 한도는 발급 조건을 따릅니다. 실제 키를 발급받아 수행한 실서비스 검증은 포함하지 않았습니다.

출처의 활성 상태가 확인되는 공고를 보여주며, 본문과 조회 시각을 함께 보관합니다. HTTP 200만으로 모집 중이라고 판단하지 않습니다. 원티드 응답에는 게시일·급여·계약 형태가 빠질 수 있어 조회 시각이나 채용 보상금으로 대신 채우지 않습니다. 검색 결과는 출처가 제공하는 순서이며 실제 지원 전에는 원문에서 다시 확인하세요.

목록 → 상세 → 보관 또는 지원 준비가 연결됩니다. 저장·지원 준비 시 상세를 다시 조회하며, 보관한 공고의 **출처 다시 조회**로 현재 본문과 상태를 갱신할 수 있습니다. 이미 만든 지원 기록의 원문 스냅샷은 변경하지 않습니다.

## 작업 공간

채용 탐색, 보관한 공고, 지원 현황, 서류 보관함, 면접 연습, 기업 노트, 템플릿, 설정이 연결돼 있습니다. 공고를 직접 보관·수정하는 기능도 유지합니다.

서류를 고치면 새 버전이 생기고, 제출 기록은 선택한 정확한 버전을 유지합니다. 면접 질문과 답변·녹음은 해당 지원 건에 연결됩니다. 문서·공고 초안은 닫기 전에 확인하며, 완료 안내는 IndexedDB 쓰기 완료 후 표시합니다. 주간 일정은 직접 기록한 면접 일시를 사용합니다.

새 공간은 **가상 자료 없이 비어 있는 상태**로 시작합니다. 이전 버전의 예시는 자동 삭제하지 않습니다. 안내의 **예시만 정리**를 누르면 삭제 범위를 확인한 후 정리하며, 직접 만든 자료와 실제 지원에 연결된 서류는 남깁니다. 정리 전에 백업하세요.

자리집의 캐릭터 지피가 랜딩과 작업 공간을 안내합니다. 검색·입력·탭·버튼은 실제로 동작하며, 모바일에서도 공고 탐색과 지원 준비를 이어갈 수 있습니다.

## 개인정보와 백업

공고 검색에 필요한 검색어·지역·공고 번호만 서버와 해당 출처로 보냅니다. 사람인 키는 서버에서만 사용합니다. 이력서 원문·첨부 파일·녹음·지원 기록·기업 메모는 서버로 보내지 않고 현재 브라우저의 IndexedDB에 보관합니다.

로그인이나 자동 동기화는 없습니다. 브라우저 데이터를 삭제하면 자료도 사라집니다. 다른 기기나 주소는 다른 저장 공간이며 `localhost`와 `127.0.0.1`도 서로 다릅니다. 한 주소를 사용하고 설정에서 JSON 백업을 내려받으세요.

저장소와 백업은 암호화 보관함이 아닙니다. 백업에는 원본 파일과 녹음이 포함됩니다. 가져오기는 검증 및 확인 후 전체 교체합니다. 문서는 파일당 6MB, PDF 최대 60페이지, 음성 녹음 최대 2분, 백업 가져오기 최대 40MB를 지원합니다. 스캔 문서 OCR과 HWP/HWPX 직접 처리는 제공하지 않습니다.

## 연결하지 않은 기능

LLM 자소서 생성·면접 평가, 음성 전사, 합격 확률 예측, 계정·클라우드 동기화와 기업으로의 자동 지원 전송은 제공하지 않습니다. 현재 면접 질문은 실제 제출 문장을 근거로 한 로컬 규칙 기반입니다. 지원 준비 버튼은 이 앱에 준비 공간을 만들 뿐 실제 지원서를 전송하지 않습니다.

## 검사

```bash
npm run typecheck
npm test
npm run build
npx playwright install chromium
CI=1 JARIZIP_TEST_PORT=4182 npm run test:e2e

# 외부 원티드 서비스를 실제 호출하는 별도 검사
npm run test:live
```

단위 검사 125개, 서버 검사 8개, 브라우저 검사 31개를 실행했습니다. 일반 브라우저 검사는 격리된 컨텍스트와 합성 자료·오디오를 사용합니다. 실제 연결 검사는 별도 명령이며 조회 제한·장애·결과 없음도 실패로 보고합니다. [검증 기록](docs/product-refresh.md)

## 배포

`npm run build` 후 Node 서버를 실행해야 공고 검색이 작동합니다. `dist/`만 정적 호스팅에 올리면 조회 API가 연결되지 않습니다. 기본 서버는 로컬 접근용이며 공개 서비스의 인증·운영 보안·도메인·자동 배포는 별도로 구성해야 합니다.
