# JariZip · 자리집

<img src="public/brand/jippi-wave.avif" width="120" alt="자리집 캐릭터 지피" />

**공고 링크와 메모를 모으고, 실제 제출한 서류 버전을 기억하는 로컬 취업 기록 도구.**

현재 배포 대상은 **소스 기반 로컬 베타**입니다. 공용 채용 검색 서비스나 Node.js가 포함된 설치형 앱이 아닙니다. 가상 공고·서류·지원 이력을 채우지 않으며, 사용자 자료는 각자의 브라우저에 보관합니다.

## 시작하기

Node.js **22.12 이상**과 npm이 필요합니다. 첫 실행에는 패키지를 받기 위한 인터넷 연결이 필요합니다.

- Windows: 소스 폴더의 `start-jarizip.cmd`를 실행합니다.
- macOS/Linux: 소스 폴더에서 `sh start-jarizip.sh`를 실행합니다.
- 터미널: `node scripts/local.mjs` 또는 `npm run local`을 실행합니다.

시작 파일은 Node 버전 확인 → 필요한 패키지 설치 → 화면 빌드 → 로컬 서버 실행 순서로 동작합니다. 브라우저에서 **`http://localhost:4178/`**를 열고, 사용하는 동안 터미널을 유지합니다. 종료는 Ctrl+C입니다. 4178 포트가 이미 사용 중이면 다른 프로그램을 종료하거나 포트를 자동 변경하지 않습니다.

직접 실행할 때는 다음 명령을 사용합니다.

```bash
npm ci
npm run build
npm start
```

실행 환경만 확인하려면 `npm run local:check`, 브라우저를 자동으로 열지 않으려면 `node scripts/local.mjs --no-browser`를 사용합니다. `node scripts/local.mjs --prepare`는 설치·빌드만 수행합니다. 개발 서버는 `npm run dev`입니다.

Linux/WSL의 기존 보조 명령 `npm run preview:start` / `npm run preview:stop`도 유지합니다. 프로젝트가 소유한 프로세스만 관리합니다. [로컬 배포 범위](docs/local-release.md)

## 공고 출처와 직접 기록

**원티드·점핏·직행의 비공식 API 자동 조회는 제공하지 않습니다.** 기존의 키 없는 자동 조회가 정상 동작했다는 사실과 공개 배포에 필요한 이용 허가는 다른 문제입니다. 원티드 공식 개인회원 약관의 자동 수집 제한과, 각 출처에 대한 허용 근거 미확인을 고려해 해당 네트워크 경로를 막았습니다. 목록 검색뿐 아니라 기존 공고 갱신과 설정의 조회 확인에도 같은 기준이 적용됩니다.

출처 사이트나 원문은 사용자가 직접 링크를 눌러 엽니다. 공고 링크와 자신이 작성한 메모를 기록할 수 있으며, 본문을 입력하는 경우 해당 내용의 이용 권한도 확인해야 합니다. 직접 추가한 공고를 자동으로 검증 완료나 접수 중이라고 표시하지 않습니다.

**사람인 공식 API**는 승인받은 사용 목적과 본인에게 발급된 서버 측 키가 있는 경우에만 선택적으로 연결합니다. 공식 안내에는 이용신청 승인·키 발급 절차와 1일 최대 500회 호출 제한이 있습니다. 키가 있다는 것만으로 공용 키 배포나 유료 재판매가 허용되는 것은 아닙니다. 연결 조건은 설정의 공고 연결 안내를 확인하세요. 이 저장소에는 실제 키가 포함되지 않으며, 실제 발급 키를 사용한 종단 검증도 포함하지 않습니다.

허용된 출처가 없으면 직접 기록·원문 이동을 안내합니다. 가상 공고로 대체하거나 이를 출처 장애로 위장하지 않습니다. 이전에 보관한 공고, 제출 당시 원문, 서류와 지원 내역은 자동 삭제하지 않습니다.

공식 안내: [원티드 약관](https://www.wanted.co.kr/terms) · [사람인 API](https://oapi.saramin.co.kr/guide/info)

## 제공 기능

공고 직접 등록·수정, 보관 목록, 지원 현황, 서류 보관함, 면접 연습, 기업 노트, 템플릿과 설정을 사용할 수 있습니다.

서류를 수정하면 새 버전을 만들고, 제출 기록에는 실제로 선택한 문서 버전과 지원 당시 공고를 연결합니다. 공고나 서류를 나중에 수정해도 이미 확정한 제출 원본을 바꾸지 않습니다. 면접 답변과 명시적으로 녹음한 음성은 해당 지원 건에 연결됩니다. 기업에 지원서를 보내거나 자동 지원하지 않습니다.

연결 가능한 공식 출처의 결과에는 30/50개씩 보기, 페이지 이동, 자동 더 보기와 마감일/게시일 정렬을 제공합니다. 정렬 범위는 **불러온 공고**이며 전체 채용 시장의 정렬 결과가 아닙니다. 날짜가 없으면 조회 시각으로 대신 채우지 않습니다. 실제 접수 여부와 정확한 종료 시각은 원문에서 확인하세요.

홈은 바로 작업 화면을 엽니다. 이용 안내는 별도로 열 수 있습니다. 밝은 청회색·흰 배경과 절제한 파랑을 사용하고, 모바일 메뉴·키보드 포커스·움직임 최소화 설정을 지원합니다. [화면 구성](docs/reference-redesign.md)

## 저장과 복구

이력서 원문·첨부 파일·녹음·지원 기록·기업 메모는 서버로 보내지 않고 **현재 브라우저의 IndexedDB**에 저장합니다. 로그인과 자동 기기 동기화는 없습니다. 브라우저 자료를 지우면 기록도 없어집니다. 다른 브라우저·프로필·주소·포트는 다른 저장 공간입니다. `localhost`와 `127.0.0.1`도 다르므로 한 주소를 계속 사용하세요.

여러 탭이 같은 자료를 수정하면 저장소의 변경 번호를 한 트랜잭션 안에서 비교해 오래된 탭이 최신 내용을 자동으로 덮어쓰지 못하도록 합니다. 충돌은 저장 성공으로 표시하지 않으며 초안 백업과 최신 내용 불러오기 등 명시적인 복구 절차를 안내합니다. 새 버전으로 바꿀 때는 이전 버전의 탭을 모두 닫으세요.

전체 JSON 백업은 **UTF-8 기준 40MB**까지 내보내고 불러옵니다. 원본 파일의 인코딩과 JSON 구조 때문에 원래 파일 용량 합계보다 커질 수 있습니다. 초과하면 복원할 수 없는 일반 백업을 만들지 않고 안내하며, 저장 자료를 삭제하지 않습니다. 40MB 초과 자료의 분할 백업은 제공하지 않습니다. 중요한 문서 원본은 별도로 보관하세요.

문서 파일은 6MB까지, PDF 텍스트 추출은 앞 60쪽까지, 음성 녹음은 최대 2분을 지원합니다. 스캔 문서 OCR, HWP/HWPX 직접 처리는 제공하지 않습니다. 백업은 암호화되지 않으며 원본 서류와 음성도 포함하므로 공개 이슈·저장소에 올리지 마세요. 공용 브라우저에서는 개인 자료를 입력하지 않는 편이 좋습니다.

## 현재 기술 구성

| 용도 | 기술 |
| --- | --- |
| 화면 | React, TypeScript, React Router, CSS, Pretendard |
| 빌드 | Vite |
| 로컬 조회 서버 | Node.js `node:http`와 `fetch` |
| 개인 자료 | IndexedDB, idb-keyval |
| 문서 처리 | PDF.js, Mammoth |
| 입력 검증 | Zod |
| 자동 검사 | Vitest, Node 테스트, Playwright |

Redis, Kafka, PostgreSQL, 계정 서버는 사용하지 않습니다. 로컬 이용에 불필요한 설치 부담을 추가하지 않습니다.

## 검사

```bash
npm ci
npm run typecheck
npm test
npm run build
npx playwright install chromium
CI=1 JARIZIP_TEST_PORT=4208 npm run test:e2e
npm run local:check
```

브라우저 검사는 격리된 컨텍스트와 명시적인 시험용 자료·가상 마이크를 사용합니다. 사용자의 브라우저 프로필이나 실제 녹음을 가져오지 않습니다. 시험용 공고 응답은 검사 코드에만 주입합니다. 자동 검사를 통과했다고 모든 OS·브라우저의 실기기 검증이나 외부 제공사의 승인이 완료됐다는 뜻은 아닙니다.

## 배포와 제공하지 않는 기능

운영자 공용 서버를 켜둘 필요 없이 사용자가 자기 PC에서 실행합니다. Windows/macOS용 서명된 설치 프로그램, Node.js 포함 단일 실행 파일, 자동 업데이트, 스마트폰 단독 설치는 제공하지 않습니다. 모바일 화면 지원과 모바일용 설치판은 구분합니다.

공용 웹서비스를 운영하려면 별도 호스팅·HTTPS·요청 제한·운영 기록·개인정보 안내·출처 이용 범위를 설계하고 검증해야 합니다. `dist/`만 정적 호스팅에 올리는 방식으로 Node 조회 API까지 제공되지는 않습니다.

LLM 자기소개서 생성·면접 평가·음성 전사·합격 확률 예측은 없습니다. 면접 질문은 제출 문장에서 만드는 규칙 기반 질문입니다.
